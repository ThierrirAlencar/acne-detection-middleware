# ClearFace Backend

ClearFace Backend is the API and AI inference service powering the **ClearFace App**, a mobile app for automated acne analysis and patient appointment management.

The project combines a modern REST API with a multimodal computer vision and biomedical NLP pipeline capable of detecting acne lesions, estimating severity, and generating human-readable clinical reports.

---

## Overview

ClearFace provides healthcare professionals and researchers with an end-to-end workflow for acne assessment:

1. Create patient appointments.
2. Upload facial images.
3. Detect acne lesions using computer vision.
4. Estimate acne severity.
5. Generate an AI-assisted clinical description.
6. Store inquiry history for future consultation.

The backend exposes REST endpoints consumed by the HTMX/Bootstrap dashboard while orchestrating the complete AI inference pipeline.

---

# Dashboard

The project includes an interactive web dashboard that allows users to:

- Authenticate users
- Create appointments
- Upload patient images
- Execute acne detection
- View detection history
- Review previous inquiries
- Visualize AI-generated results
- Inspect generated detection artifacts

The dashboard communicates exclusively with the backend through REST endpoints using HTMX, providing a lightweight and responsive user experience without requiring a heavy frontend framework.

---

# AI Pipeline

ClearFace implements a multimodal AI pipeline composed of three specialized models.

## 1. YOLO

YOLO performs the computer vision stage responsible for:

- Acne lesion detection
- Lesion localization
- Bounding-box generation
- Detection confidence estimation

The detected lesions are rendered into an annotated output image.

---

## 2. Dlib

Dlib performs facial landmark extraction and geometric facial analysis.

Its responsibilities include:

- Face detection
- Facial landmark estimation
- Region segmentation
- Support for GAGS severity computation

When facial landmarks cannot be extracted reliably, the system gracefully reports that severity estimation could not be completed.

---

## 3. BioGPT-4

BioGPT-4 acts as the clinical reasoning layer.

Using the structured outputs generated by YOLO and Dlib, BioGPT-4 produces:

- Clinical summaries
- Acne severity descriptions
- Human-readable diagnostic explanations
- Natural language reports suitable for healthcare workflows

This separation between visual analysis and biomedical language generation provides interpretable AI-assisted results rather than raw model predictions.

# Running the Project

Clone the repository:

```bash
git clone https://github.com/your-org/clearface-backend.git
cd clearface-backend
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it:

Linux/macOS

```bash
source .venv/bin/activate
```

Windows

```powershell
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Configure environment variables:

```env
DATABASE_URL=sqlite:///clearface.db
SECRET_KEY=your_secret_key
...other keys described at .env.example
```

Run the application:

```bash
flask --app main run -h <your host> -p <your port>
```

The API will be available at:

```
http://<your host>:<your port>
```

OpenAPI documentation:

```
http://<your host>:<your port>/docs
```
